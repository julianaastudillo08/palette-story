# Palette Story

**EN:** Color storytelling studio — pick five brand colors, auto-generate WCAG contrast pairs, export CSS custom properties, and preview buttons, cards, and nav with your palette. Dark creative atmosphere.

**ES:** Estudio de narrativa cromática — elige cinco colores de marca, genera pares de contraste accesibles, exporta variables CSS y previsualiza botones, tarjetas y navegación. Ambiente creativo oscuro.
